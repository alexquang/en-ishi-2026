== Description ==
Advanced Redis object cache backend for WordPress. 
Supports Predis, PhpRedis, Relay, sentinel, clustering, and WP-CLI.

== Installation ==
1. Upload to /wp-content/plugins/
2. Activate
3. Configure in Settings > Redis Cache
